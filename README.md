# home-clock

シンプルな静的時計アプリ。現在時刻を大きく表示し、クエリ文字列でタイムゾーンを切り替えられます。現在気温と天気マークも表示します（[Open-Meteo](https://open-meteo.com/) 使用、APIキー不要）。

## 使い方

| URL | 説明 |
|-----|------|
| `/` | ブラウザのローカルタイムゾーン |
| `/?tz=Asia/Tokyo` | 東京 |
| `/?tz=America/New_York` | ニューヨーク |
| `/?timezone=Europe/London` | ロンドン（`timezone` パラメータも可） |
| `/?tz=Asia/Tokyo&subtz=America/New_York` | 東京の主時計とニューヨークのサブ時計 |
| `/?until=2026-12-31T23:59:59+09:00` | 指定日時までのタイマー（経過後はマイナス） |
| `/?until=2026-12-31T23:59:59+09:00&event=Release` | イベント名付きのタイマー |
| `/?weather=off` | 天気表示を無効化 |
| `/?wloc=osaka` | 天気の取得地点をプリセット名で指定（タイムゾーンとは独立） |
| `/?wloc=大阪` | 天気の取得地点を地名で指定（ジオコーディングで座標に解決） |
| `/?wloc=34.6937,135.5023&loc=大阪` | 天気の取得地点を緯度経度で指定（`loc` は地点名表示） |

無効なタイムゾーンが指定された場合は、ローカルタイムゾーンにフォールバックします。

`subtimezone` は `subtz` の別名としても使えます。`until` は次のような形式に対応しています。

- `08:30`（主タイムゾーンの次回の08:30）
- `01:00:00+10:30`（時刻だけ＋オフセット。そのオフセットでの次回のその時刻）
- `2026-12-31 08:30` / `2026年12月31日 8時30分`（タイムゾーンは主タイムゾーン）
- `2026-12-31 08:30 Asia/Tokyo`（末尾にタイムゾーンを指定）
- `2026-12-31T08:30:00+09:00`（ISO 8601のオフセット付き）

日付を省略した場合は次回の時刻、タイムゾーンを省略した場合は主タイムゾーンとして解釈します。

`event` を指定すると、タイマーの目標が `until Release (2026.12.31 (Thu) 23:59)` のように表示されます。

## 天気表示

時刻の下に、現在気温と天気マーク（WMO weather code を絵文字に変換、昼夜で切替）を表示します。天気表示はクエリ文字列がある場合のみで、素のURL（クエリなし）では表示しません。15分ごとに自動更新します（ページを読み込んだ時点が基準。読み込み直後に取得し、以後15分間隔で再取得）。取得に失敗した場合は天気欄自体を表示しません（時計表示は継続します）。

取得地点は天気専用の `wloc` パラメータで指定し、タイムゾーン（`tz`）とは連動しません。

- プリセット名: `tokyo` / `osaka` / `nagoya` / `kyoto` / `sapporo` / `sendai` / `hiroshima` / `fukuoka` / `naha` / `seoul` / `shanghai` / `hongkong` / `taipei` / `singapore` / `bangkok` / `kolkata` / `dubai` / `london` / `paris` / `berlin` / `moscow` / `newyork` / `chicago` / `denver` / `losangeles` / `toronto` / `saopaulo` / `sydney` / `auckland`
- 地名: `wloc=大阪` や `wloc=京都` のように地名をそのまま書くと、[Geocoding API](https://open-meteo.com/en/docs/geocoding-api) で座標に解決します（町名・区レベルの細かさまで指定可能。データベースにない地名は解決できません）
- 緯度経度: `wloc=34.6937,135.5023` の形式。地点名を表示したい場合は `loc` パラメータを併用
- 未指定・解決できない指定の場合は東京

位置情報（geolocation）は使いません。キャスト先の画面で許可ダイアログを出さずに済ませるためです。
