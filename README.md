# timezone-clock

シンプルな静的時計アプリ。現在時刻を大きく表示し、クエリ文字列でタイムゾーンを切り替えられます。現在気温と天気マークも表示します（[Open-Meteo](https://open-meteo.com/) 使用、APIキー不要）。

## 使い方

| URL | 説明 |
|-----|------|
| `/` | ブラウザのローカルタイムゾーン |
| `/?tz=Asia/Tokyo` | 東京 |
| `/?tz=America/New_York` | ニューヨーク |
| `/?timezone=Europe/London` | ロンドン（`timezone` パラメータも可） |
| `/?tz=Asia/Tokyo&subtz=America/New_York` | 東京の主時計とニューヨークのサブ時計 |
| `/?until=2026-12-31T23:59:59+09:00` | 指定日時までのタイマー（経過後はマイナス） |
| `/?until=2026-12-31T23:59:59+09:00&event=Release` | イベント名付きのタイマー |
| `/?weather=off` | 天気表示を無効化 |
| `/?lat=35.6812&lon=139.7671&loc=東京駅` | 天気の取得地点を緯度経度で指定（`loc` は地点名表示、省略可） |

無効なタイムゾーンが指定された場合は、ローカルタイムゾーンにフォールバックします。

`subtimezone` は `subtz` の別名としても使えます。`until` は次のような形式に対応しています。

- `08:30`（主タイムゾーンの次回の08:30）
- `2026-12-31 08:30` / `2026年12月31日 8時30分`（タイムゾーンは主タイムゾーン）
- `2026-12-31 08:30 Asia/Tokyo`（末尾にタイムゾーンを指定）
- `2026-12-31T08:30:00+09:00`（ISO 8601のオフセット付き）

日付を省略した場合は次回の時刻、タイムゾーンを省略した場合は主タイムゾーンとして解釈します。

`event` を指定すると、タイマーの目標が `until Release (2026.12.31 (Thu) 23:59)` のように表示されます。

## 天気表示

時刻の下に、現在気温と天気マーク（WMO weather code を絵文字に変換、昼夜で切替）を表示します。30分ごとに自動更新し、取得に失敗した場合は天気欄自体を表示しません（時計表示は継続します）。

取得地点の決め方:

1. `lat` / `lon` パラメータがあればその地点（範囲外・数値でない場合は無視）
2. なければ主タイムゾーンに対応する代表都市（東京、ニューヨーク、ロンドンなど主要都市のみ内蔵）
3. それもなければ東京

位置情報（geolocation）は使いません。キャスト先の画面で許可ダイアログを出さずに済ませるためです。
